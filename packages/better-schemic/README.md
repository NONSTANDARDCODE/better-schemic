# better-schemic

The [Better-schemic](https://github.com/NONSTANDARDCODE/better-schemic) CLI — schema-as-code migrations for any database.

This is a convenience alias for [`@better-schemic/cli`](https://www.npmjs.com/package/@better-schemic/cli): it lets
you run the CLI as `bunx better-schemic` / `npx better-schemic` (or install it for the `better-schemic` / `sc` bins). To
start a new project use `bun create better-schemic`; to add Better-schemic to an existing one, `better-schemic init`.
